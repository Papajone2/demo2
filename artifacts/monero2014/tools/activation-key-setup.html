Wallet-name reporting
Public-key setup

Operator tool, not a wallet recovery screen. It generates a public configuration file locally in your browser. Nothing you enter here is uploaded.

No recovery phrase or private key belongs here.

Each report uses a fresh AES-256-GCM key. Your RSA public key protects that key; the matching private key stays on your server. Wallet seeds use separate device-local protection and are never included.

Not the secret webhook URL. The relay keeps your webhook credentials server-side.

Newly disclosed wallets report after their first confirmed incoming payment and completed scan. Existing wallets are not silently enrolled. Reports pause while Tor is enabled.

Where to put the downloaded file

Replace artifacts/monero2014/config/activation-reporting.json, then build a new APK through GitHub Actions.

Configure the server-only secret WALLET_ACTIVATION_WEBHOOK_URL and a persistent WALLET_ACTIVATION_LEDGER_DIR. Keep private keys out of this file, the APK and Git.

The server can observe report timing and connection information. This counts disclosed wallet installations, not unique people. The receiver must deduplicate eventId because retries can occur.
